Используй этот инструмент, только когда работа упёрлась в решение, которое по-настоящему принимает пользователь: его нельзя вывести из запроса, из кода или из разумных умолчаний.

Как пользоваться:
- пользователь всегда может выбрать «Other» и ответить своим текстом
- multiSelect: true — когда на вопрос можно выбрать несколько ответов
- рекомендуемый вариант ставь первым и допиши в конце его метки «(Recommended)»

Предпросмотр:
Необязательное поле `preview` у вариантов — для конкретных артефактов, которые пользователю нужно сравнить глазами:
- макеты интерфейса в ASCII
- фрагменты кода с разными реализациями
- варианты схем
- примеры конфигурации

Предпросмотр рисуется как markdown в моноширинной рамке, многострочный текст поддерживается. Если предпросмотр есть хотя бы у одного варианта, интерфейс показывает варианты списком слева, а предпросмотр — справа. Для простого выбора, где хватает метки и описания, предпросмотр не нужен. Предпросмотр бывает только у вопроса с одиночным выбором (не multiSelect).
