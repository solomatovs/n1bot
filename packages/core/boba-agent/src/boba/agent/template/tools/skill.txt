Запустить скилл.

Скилл — готовый набор инструкций, который пользователь или проект завёл для задач определённого вида (шаги выкатки, список проверок ревью, порядок работы в репозитории). Доступные скиллы приходят списком в system-reminder с описанием в одну строку. Если текущую задачу покрывает скилл из списка, сначала вызови этот инструмент: инструкции скилла загрузятся в ход, и ты следуешь им вместо своего обычного подхода. Пользователь может попросить скилл по имени (`/<имя>`, «слэш-команда») — это просьба его запустить.

Параметры:
   - `skill` — точное имя из списка, без ведущего слеша
   - `args` — аргументы для скилла, если они нужны

Годятся только имена из списка (или те, что пользователь написал сам).
