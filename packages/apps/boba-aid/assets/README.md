# Ассеты интерфейса

Оформление и переводы чата aid. Каталог сам по себе — готовый
корень статики chainlit: файлы лежат ровно там, где их ищет chainlit
(`CHAINLIT_APP_ROOT`); программа ставит его на `share/` своего каталога.

- `.chainlit/config.toml` и `.chainlit/translations/*.json` (в том числе русский
  `ru-RU.json`) — настройки и переводы интерфейса;
- `chainlit.md` — стартовая страница; в `.chainlit/` chainlit её не ищет;
- `public/` — тема `theme.json`, стили `ui.css`, логотипы, favicon, аватар
  ассистента `n1-avatar.svg`, элементы и скрипт страницы;
- `mcp-apps/sandbox.html` — страница-прокси песочницы MCP Apps, в которой чат
  рисует приложения MCP-серверов. Отдаёт её сам чат, но не на своём порту, а на
  порту песочницы сервера (`[mcp.servers.<имя>.apps] port`): там нет ничего,
  кроме этой страницы в корне и шрифта чата из `public/vendor/inter/files` по
  пути `/fonts/inter/files/`. На источнике чата скрипт приложения добрался бы
  до его страницы (docs/admin-guide.md, разделы 5 и 13).

Развёртывание копирует набор в `share/` каталога программы образа
(Dockerfile) и релиза (`make release`). Отладка и тесты из исходников отдают
каталог напрямую, поэтому правка ассета видна без сборки; собранный фронт
(`ui/`, `public/page.js`, `public/vendor`) кладёт сюда `make web`. Писать в статику приложение не
должно: вложения сессий chainlit уходят в `files/` каталога данных экземпляра,
а не в `.files` рядом с ассетами.
