# Идентификация пользователей и схема хранения

Личность пользователя задаётся каноническим `login`. Строковый идентификатор
равен логину; UUID пользователя принадлежит его хранилищу. AID, MCP и служба Boba используют независимые схемы users/roles.

Целевая структура описана в [SQL-версии 0002](../2026-11-04-normalized-users/README.md).
Команда `migrate` приводит объявленные объекты к выбранной версии независимо
от истории установки. Ей не нужны соответствия пользователей, исходная версия
схемы или планы переноса данных. Содержимое пользователей и истории она не
сопоставляет и не импортирует.

В схеме службы `session.user_id` ссылается на `users.id`, а
`session_records.session_id` — на `session.id`. Локальные stdio-сессии могут
иметь `user_id NULL`. Преобразование строкового владельца истории в UUID
не входит в создание этой структуры.
