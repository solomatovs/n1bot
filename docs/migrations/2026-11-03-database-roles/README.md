# Пользователи и роли в PostgreSQL

Структуру users/roles/user_roles задаёт выбранная SQL-версия приложения.
Для текущего кода используется [версия 0002](../2026-11-04-normalized-users/README.md).
В users обязателен уникальный `login`; членство хранится в user_roles.
Колонка `managed` различает автоматические и ручные назначения ролей.

`migrate` создаёт и изменяет структуру хранения. Создание ролей, назначение
прав, извлечение личности из JSON и перенос членства в его задачи не входят.
Администратор управляет ролями отдельно, а обычный вход синхронизирует
подтверждённые автоматические назначения через UsersTable.
