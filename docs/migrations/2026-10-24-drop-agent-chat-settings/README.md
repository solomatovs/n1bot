# Снятие таблицы agent_chat_settings

Чат (boba-aid) больше не хранит снимок настроек агента на тред. Удаление треда
собирает всё из текущего состояния: в режиме службы агента входит в неё от имени
владельца треда (логин и роли — из его строки `users`), в режиме своего процесса
поднимает короткий процесс агента по текущему профилю треда из `[profiles]`.
Таблицу `agent_chat_settings` приложение больше не создаёт; в уже развёрнутых базах
её снимает этот скрипт. Секция `[agent.settings_table]` из конфига чата удалена:
конфиг с ней не пройдёт проверку, её надо убрать из site- и compose-конфигов.

Запуск под ролью, которая владеет схемой чата, после выкатки новой версии:

```sh
psql "<строка подключения к базе чата>" -v ON_ERROR_STOP=1 -v aid_schema=aid -f drop.sql
```

`aid_schema` — схема чата (`[app].schema`), по умолчанию `aid`. Скрипт
повторяемый: таблицы нет — ничего не делает. Данные таблицы не нужны: это копия
профиля модели и владельца треда, которую чат собирает заново.
